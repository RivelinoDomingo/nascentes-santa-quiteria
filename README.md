# 🌊 Projeto APP Nascentes STQ

Repositório dedicado ao armazenamento, organização e disponibilização de arquivos de pesquisa, levantamento de campo e mapeamento das **Áreas de Preservação Permanente (APP)** das nascentes de Santa Quitéria (Ibitiara - BA).

---

## 📌 Sobre o Projeto

Este projeto tem como objetivo catalogar, mapear e definir estratégias de proteção para os recursos hídricos, cursos d'água e olhos d'água da comunidade de Santa Quitéria. As ações buscam a adequação ambiental e a segurança hídrica local com base no Código Florestal Brasileiro (Lei nº 12.651/2012).

---

## 📂 Estrutura e Arquivos do Repositório

| Arquivo / Pasta | Formato | Descrição |
| :--- | :--- | :--- |
| `Projeto APP Nascentes STQ Final.kmz` | `.kmz` | Arquivo geoespacial compactado para visualização no **Google Earth**. Contém o mapa da área, nascentes catalogadas e delimitações dos perímetros de interesse. |
| `Projeto APP Santa Quitéria.kml` | `.kml` | Arquivo de dados vetoriais para **Google Earth** / GIS com marcações de pontos e delimitações da área de estudo. |
| `projeto_preservacao_nascentes-STQ.odt` | `.odt` | Documento de texto em formato aberto com o levantamento completo, justificativas técnicas e resumo das ações do projeto. |
| `Images/` | Diretorio | Pasta contendo os registros fotográficos de campo das nascentes, vegetação de entorno (mata ciliar) e capturas de tela do mapeamento. |

---

## 🗺️ Como Visualizar os Mapas no Google Earth

1. Baixe o arquivo `Projeto APP Nascentes STQ Final.kmz` ou `Projeto APP Santa Quitéria.kml`.
2. Abra o software [Google Earth Pro](https://www.google.com/earth/versions/#earth-pro) no computador ou o aplicativo **Google Earth** no celular.
3. Importe o arquivo baixado (`Arquivo > Abrir...`).
4. Navegue pelos pontos catalogados, limites das APPs e divisões territoriais marcadas.

## 📷 Registros Fotográficos

A pasta `Images/` contém os registros de campo utilizados tanto na documentação técnica quanto na interface web do projeto. As fotos documentam:
* Nascentes e olhos d'água identificados.
* Cursos d'água e riachos da região.
* Estado da mata ciliar e vegetação de entorno.
* Mapeamento via satélite das áreas de interesse.
